# 🛒 Flexible E-Commerce Store

A lightweight, modern, and mobile-first e-commerce web application designed for small businesses, local shops, and independent merchants. It features a versatile and adaptable design that can easily fit any retail category—whether it's electronics, fashion, groceries, pet supplies, or local crafts—offering a seamless shopping and management experience without the complexity of heavy platforms.

---

## ✨ Key Features

### 🛍️ Customer Experience (Storefront)
* **Mobile-First Design:** Fully responsive interface optimized for smartphones and quick browsing.
* **Category Filtering:** Horizontal, smooth-scrolling category chips for easy navigation across different departments.
* **Smart Shopping Cart:** Clean cart management with real-time total calculations.
* **Direct WhatsApp Checkout:** Converts cart items into a formatted order message sent directly to the store’s WhatsApp number.

### ⚙ Admin Dashboard
* **Product Management:** Easily add, edit, or delete products with image uploading support.
* **Optional Descriptions:** Flexible product creation allowing items to be posted with or without descriptions.
* **Category Management:** Dynamically add or remove product categories to match your store's niche.
* **Search Functionality:** Quick product search within the dashboard.
* **Dark / Light Mode:** Built-in theme toggler for comfortable admin management day or night.

---

## 🛠️ Technology Stack
* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, Bootstrap 5 (RTL)
* **Icons & Fonts:** FontAwesome 6, Google Fonts (Zain)

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Import the database structure into your MySQL server (using `db.php` for connection settings).
3. Ensure the `uploads/` directory has write permissions for product images.
4. Run the project on a local server (like XAMPP or Laragon) or deploy it to your hosting server.
